## فلسفة النظام

> **هذا ليس Jira ولا ServiceNow.**  
> منصة عمليات لشهر واحد — بديل Excel وWhatsApp.

### كل شيء = **حالة (Case)**

| النوع | المعنى |
|-------|--------|
| خلل (Bug) | مشكلة تقنية → تُعيَّن لمطور |
| سؤال | استفسار |
| تدريب | يحتاج توعية |
| ملاحظة | للتوثيق |
| طلب ميزة | تحسين مستقبلي |
| شكوى | شكوى ميدانية |

### مسار الحالة

```
جديد → قيد المعالجة → محلول → مغلق
```

## سير العمل

### 1. سوبر أدمن / مدير الدعم — إنشاء خلل

1. اذهب إلى **الحالات → إنشاء حالة** (`/cases/create`)
2. اكتب الوصف — **AI يقترح** النوع والأولوية والمطور
3. ارفع **صور وملفات** (حتى 10 MB)
4. اختر نوع **خلل** + **المطور**
5. اضغط **إنشاء الخلل وتعيين المطور**
6. المطور يستلم **إشعار** (داخل التطبيق + بريد)

### 2. مدير الدعم — مراجعة

- **لوحة التحكم** تعرض:
  - بانتظار مراجعتي
  - عند المطورين
  - محلولة — بانتظار تأكيد
  - توزيع الحالات حسب النوع
- من تفاصيل الحالة: **قبول وإغلاق** أو **إرجاع للمطور**

### 3. المطور

- يرى **أعطاله فقط** في `/cases` و `/dashboard`
- يكتب الحل + يحدد «يتطلب نشر»
- يرسل للمدير → إشعار تلقائي

### 4. الدعم الفني المراكز

- `/report` — يرسل حالة بسيطة
- AI يساعد بالتصنيف

## البنية التقنية

- **Next.js 15** + TypeScript + Tailwind
- **SQLite** + Prisma (قاعدة بيانات محلية)
- **NextAuth** للمصادقة
- **React Query** للبيانات
- الملفات المرفوعة: `public/uploads/`

## استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| صفحة 500 أو `Cannot find module` | `npm run fix` أو `npm run dev:clean` |
| الموقع لا يستجيب | أوقف كل نوافذ `npm run dev` ثم `npm run fix` |
| لا يقبل الدخول | امسح الكوكيز، سجّل مجدداً |
| بيانات قديمة | `npm run db:setup` ثم أعد الدخول |

**مهم:** لا تشغّل `npm run build` أثناء تشغيل `npm run dev` — يفسد مجلد `.next`.
